# Programmiercode aus dem Buch "Let's code Scratch!" von Hauke Fehr

1. Datei mit Programmiercode aus diesem Ordner herunterladen.
2. Scratch starten.
3. Auf "Datei" klicken (oben links).
4. Dann auf "Load from your computer" klicken (das bedeutet: "Von deinem Computer laden").
5. Dann den Ordner finden, in dem sich die Datei befindet.
6. Datei doppelt anklicken.
